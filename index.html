File ini berfungsi sebagai pembungkus iframe aplikasi Google Apps Script Anda. Lakukan 3 langkah berikut:

  1. Buka file index.html ini di GitHub (tombol pensil / Edit).
  2. Ganti nilai WEBAPP_URL pada bagian CONFIG (awal blok <script>) dengan URL Web App Anda — yang berakhiran /exec.
  3. Commit perubahan → tunggu ±1 menit → muat ulang halaman ini.

Jika URL sudah benar namun panel ini masih muncul, pastikan tidak ada spasi atau karakter tambahan pada URL.
